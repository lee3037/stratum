# 使用指南

[← 返回 README](../README.md)

## 转换 PDF

前置条件：服务已启动。部署方法见[部署](deployment.md)。浏览器不限。

步骤：

1. 在浏览器中打开 `http://<服务器>:8000/`。
2. 选择你负责的知识库。没有时点击「新建知识库」，名称建议与 FastGPT 中的知识库一致。
3. 点击 PDF 列表右上的上传按钮：
   - 「上传 PDF」：可以多选。
   - 「上传文件夹」：保留子目录结构。
   - 也可以把 PDF 或文件夹直接拖进页面。只拖入一个 PDF 时，系统上传后直接开始解析。
4. 在 PDF 列表中点击一个 PDF，在抽屉中点击「开始解析分块」。
5. 在「解析配置」中确认参数，点击「开始解析」。
6. 在「分块」视图中校对内容。点击页码对照原文。
7. 点击「保存到知识库」或按 `Ctrl/⌘ S`。

系统使用 PyMuPDF + RapidOCR 在本机解析。参数说明见[解析配置](configuration.md)。

多人同时使用时：

- 单个解析优先于批量解析。即使服务器正在跑别人的大批量任务，你点「解析」后通常也只需多等一个页面分组的时间。
- 同时解析的人较多时，各文件轮流处理，进度会慢一些但都在前进。如果提示「当前正在解析的文件较多，请稍后再试」，等一会儿再点。
- 提示「服务器磁盘剩余空间不足」时，无法上传和保存，请联系管理员。
- 提示「解析进程意外退出」时，可以再试一次；同一个 PDF 反复出现时，请把文件交给管理员排查。

> [!NOTE]
> 地址栏会带上知识库名称，例如 `http://<服务器>:8000/?kb=安全规程库`。收藏这个地址，下次直接进入。浏览器也会记住上次打开的知识库。

## 知识库与版本

- 存储：每个知识库是服务器 `STRATUM_DATA_DIR` 下的一个子目录。PDF 和解析结果都保存在其中，所有人看到的是同一份文件。列表每 15 秒自动刷新。
- 默认参数：每个知识库有一组默认的解析和分块参数，只能在「知识库设置」（页头知识库名称旁的设置按钮）中修改。解析时在抽屉里临时调整的参数只对那一次有效。
- 上传同名文件：内容相同时跳过；内容不同时自动改名为 `名称(2).pdf`，不覆盖原文件。
- 版本命名：第一次生成的文件名为 `文件名_v1.md`。再次生成时依次使用 `_v2`、`_v3`，旧版本保留。原有的无后缀 `.md` 文件按第 1 版计数，文件名保持不变。
- 版本号：保存时由服务器分配。预定的版本号已被其他人占用时，系统顺延到下一个空闲版本号并提示。
- 修改已保存的版本：如果其他人在你打开之后修改过同一文件，保存会失败并提示，不会覆盖对方的修改。重新打开该版本后再编辑。
- 删除：界面不提供删除。需要删除时，由管理员在服务器上操作。

> [!WARNING]
> 未保存的版本只存在于当前页面中。关闭页面前，保存或下载这些版本。

## 批量处理

点击 PDF 列表右上的「批量处理」按钮，主区域切换到批量视图。

1. 用搜索框和「全部 / 未转换 / 已转换」筛选文件，勾选要处理的 PDF。表头的复选框可以全选当前列表。
2. 点击「批量解析」，确认解析参数，点击「开始批量解析」。
3. 在「最近的批次」中查看进度。展开批次可以看到每个文件的状态、页数、块数和失败原因；点击完成的文件可以打开结果校对。

- 批量解析在服务器上进行。每完成一个文件，结果自动保存为该 PDF 的新版本。关闭页面或服务重启都不会丢失进度，重启后未完成的文件自动重新排队。
- 默认勾选「跳过已转换的文件」，已有解析结果的 PDF 不会再生成新版本。
- 「取消剩余」只取消还在排队的文件，正在解析的文件会完成并保存。
- 批次结束后，「重试」重新处理失败或取消的文件。
- 多个批次同时进行时，服务器在各批次之间轮流处理，不会让某个大批次独占资源。
- 批量解析让路给单个解析：有人点「解析」时，批量任务暂时放慢，单个解析完成后恢复。
- 已在其他批次中排队或解析的文件，再次加入新批次时会跳过，并在明细中注明。

### 打包下载

在批量视图中选择下载内容，点击「下载所选」（未勾选时为「下载整个知识库」），或在批次上点击「下载本批结果」。

| 下载内容 | 说明 |
| --- | --- |
| FastGPT 导入格式 | 每个 PDF 只取最新版本，文件名去掉 `_vN`，例如 `操作规程.md` |
| 最新版本 | 每个 PDF 只取最新版本，保留版本号 |
| 全部版本 | 每个 PDF 的所有版本 |

- zip 保留子目录结构，可以选择同时包含 PDF 原文。
- zip 中附带 `汇总.csv`：每个文件的页数、块数、OCR 页数、来源、保存时间，以及批次中的状态和失败原因。用 Excel 可以直接打开。
- 「下载本批结果」取该批次生成的版本，即使之后有人又保存了新版本。

## 导入 FastGPT

前置条件：管理员已在服务端配置 FastGPT 地址和 API 密钥，见[部署](deployment.md#fastgpt)。

### 绑定知识库

1. 点击页头知识库名称旁的设置按钮，打开「知识库设置」。
2. 在「FastGPT 知识库」中选择对应的 FastGPT 知识库。列表来自 FastGPT，文件夹中的知识库显示为「文件夹 / 知识库」。
3. 确认下方的默认分块参数，点击「保存设置」。

每个 Stratum 知识库绑定一个 FastGPT 知识库。导入时，FastGPT 按版本保存时使用的自定义分隔符分块，与 Stratum 中看到的分块一一对应，不需要在 FastGPT 中手动设置。

### 导入

导入是单独的操作，解析和保存都不会自动导入。

- 单个文件：打开一个已保存的版本，点击结果工具栏右侧的「导入 FastGPT」。导入的是当前打开的版本。未保存的版本要先保存。
- 批量：在「批量处理」中勾选文件，点击「导入所选」；不勾选时为「导入全部待导入」，即所有「有新版本、导入后又修改过、或上次导入失败」的文件，每个 PDF 导入最新保存的版本。

导入规则：

- 每个 PDF 在 FastGPT 中对应一个集合，集合名为去掉 `_vN` 的文件路径，例如 `规程/操作规程.md`。
- 导入新版本时，系统先创建新集合，成功后删除旧集合。删除旧集合失败时保留新集合并提示，可以在 FastGPT 中手动删除旧集合。
- 版本已导入且没有修改时，再次导入会提示「内容没有变化」，不重复创建。
- FastGPT 中已有同名集合、但不是通过 Stratum 导入的（例如以前手动导入的）：单个导入时询问替换还是保留两份；批量导入按「遇到同名集合」的设置处理，默认跳过并在结果中列出。

### 导入状态

| 位置 | 显示 |
| --- | --- |
| 左侧 PDF 列表 | 已导入 / 待导入 |
| 批量处理的 FastGPT 列 | 已导入 vN / 有更新 / 待导入 / 导入失败 |
| 结果工具栏 | 已导入 FastGPT · N 块 / 已修改，需重新导入 / FastGPT 中为其他版本 / 未导入 |

更换绑定的 FastGPT 知识库后，原知识库中已导入的集合不会被删除，状态按新知识库重新计算。

## 导入其他 RAG 知识库

Stratum 输出的 `.md` 文件用分隔符隔开每一块。任何支持「自定义分隔符分块」的知识库都可以直接导入。

1. 在目标知识库中导入 `.md` 文件。
2. 把分块方式设为按自定义分隔符分块。
3. 填入与 Stratum 相同的分隔符。默认分隔符是 `===CHUNK===`。
4. 把知识库的最大分块长度设为不小于 Stratum 的「最大字数」。

> [!IMPORTANT]
> 如果知识库的最大分块长度小于 Stratum 的「最大字数」，知识库会把块再次截断。

<details>
<summary>示例：FastGPT</summary>

1. 新建或打开知识库。
2. 选择文本数据集，通过本地文件导入 `.md` 文件。
3. 把处理方式设为「直接分块」。
4. 把分块模式设为「自定义分隔符」，填入 `===CHUNK===`。
5. 把「最大分块大小」设为不小于 Stratum 的「最大字数」。
